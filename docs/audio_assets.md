# 音频资源规范

本规范仅适用于 `D:/godot/demo/demo2`（Lunar）。开发约束见 [AGENTS.md](../AGENTS.md)，运行结构见 [架构说明](architecture.md)，完成状态见 [项目状态](project_status.md)，项目入口见 [README](../README.md)。图片和字体继续维护在美术规范，音频使用独立的目录及清单。

## 目录与来源

| 路径 | 职责 |
| --- | --- |
| `assets/audio/bgm/` | 项目实际引用的背景音乐原文件及 `.import` 设置 |
| `assets/audio/manifest.json` | 音频稳定 ID、原文件名、项目路径、格式、帧数、循环范围和 SHA-256 |
| `resources/audio/gameplay_bgm.tres` | Hide/SEEK 双 clip 与转换规则 |
| `scripts/audio/bgm_controller.gd` | 常驻 BGM 播放、场景状态切换、暂停和恢复 |
| `default_bus_layout.tres` | Master、BGM、SFX 音频总线及输出关系 |
| `scripts/ui/game_settings.gd` | 音量和亮度偏好加载、实时应用与保存 |

用户提供的微信来源文件原样复制到项目内，运行时全部使用 `res://` 路径。微信下载目录只作来源记录，不作为运行依赖。替换文件时保留稳定 ID 与引用路径，并更新 [音频清单](../assets/audio/manifest.json)；音频不写入 `assets/art/manifest.json`。

| 原文件 | 项目文件 | 稳定 ID | 用途 |
| --- | --- | --- | --- |
| `Hide.wav` | `assets/audio/bgm/hide.wav` | `bgm_hide` | 自由探索、普通查看和普通对白 |
| `SEEK.wav` | `assets/audio/bgm/seek.wav` | `bgm_seek` | 四处谜题、前置剧情、微剧情及 CG；第五幕黑底回忆、装置对白与结局正文 |

两份原文件各为 42,287,278 字节，格式为双声道 PCM32 WAV（`pcm_s32le`），采样率 48,000 Hz，均有 5,285,648 个采样帧，时长约 110.1176667 秒。原文件字节与 SHA-256 保留，具体校验值记录在音频清单。

## 导入与循环

两份 WAV 使用相同导入参数，保留 `.import` 文件随项目交付。项目 `.gitattributes` 将 `*.wav` 标记为 `binary`，WAV 按二进制资产随项目保留。

| 导入字段 | 当前值与含义 |
| --- | --- |
| `compress/mode` | `0`，无压缩运行 PCM16；源文件仍保留 PCM32 字节 |
| `edit/trim`、`edit/normalize` | 均为 `false`，不裁剪或归一化 |
| `force/8_bit`、`force/mono`、`force/max_rate` | 均为 `false`，不强制 8-bit、单声道或重采样 |
| `edit/loop_mode` | `2`，导入器的 Forward 循环选项 |
| `edit/loop_begin` | `0`，从首帧开始循环 |
| `edit/loop_end` | `-1`，全曲末尾；导入器映射至末帧 `5285647` |

导入器 `edit/loop_mode = 2` 与运行时 `AudioStreamWAV.loop_mode = 1` 都表示 Forward，各自枚举值不同，配置时按所在接口使用。当前两轨均使用 `begin 0 / end -1` 全曲循环；末帧索引为 `5285647`，原始总帧数为 `5285648`。替换时同步两条音轨的采样率、帧长、循环起止和音乐起点，避免裁剪、重采样或单独偏移某一轨。

相同采样帧数和循环参数支持同位置切换的配置，乐句与循环边界的听感仍需用户确认。静态格式及校验结果不作为无缝试听通过的结论。

## 播放与切换

`main.tscn` 的常驻 `BGM` 节点挂 `bgm_controller.gd`，使用单个 AudioStreamPlayer 播放 `AudioStreamInteractive`。同一资源的 clip 0 名为 `Hide`，clip 1 名为 `Seek`（原曲名 SEEK）；两个方向均配置 `IMMEDIATE + SAME_POSITION + FADE_CROSS`，保持当前位置切换。

`fade_beats = 0.03`。当前 WAV 无 BPM，该配置对应约 30 ms 的逐采样交叉平滑，用于切换瞬间衔接。播放器默认音量仍为 `-6 dB`，由控制器导出属性调整，输出至 `BGM` bus，再汇入 `Master`。设置页通过总线增益调整音量，保留播放器基准音量及当前播放时间。

| 时机 | 音乐行为 |
| --- | --- |
| 主菜单、整段开场、卧室淡入完成之前 | 不开始播放音乐；返回主菜单时已有会话的音频暂停 |
| 进入可自由操作的游戏界面 | 首次从 0 开始 Hide；继续会话时从暂停位置恢复 |
| 打开水井、鱼缸、洗笔桶或帐篷收纳盒谜题 | 同位置切换 SEEK，覆盖前置剧情、选碎片、填词、微剧情和 CG；微剧情读完回谜题时保持 SEEK |
| `return_started` 或 Esc 关闭谜题 | 同位置切回 Hide，后续普通对白保持 Hide |
| 情节块 4 完整读完，继续第五幕黑底正文 | 保持 SEEK；真实回忆后的探索提示、退出剧情或进入终局页时切回 Hide |
| 点击意识深潜装置 | 同位置切换 SEEK，覆盖装置正文、选择页和结局正文 |
| 普通收集、图片、对白、地点切换 | 保留当前 BGM 播放时间，不重新开始 |
| 暂停或返回主菜单 | 冻结音频时间；继续时恢复同一位置 |
| 主菜单或暂停界面打开设置 | 保持会话音频冻结；拖动音量仅调整总线增益，返回设置来源页面后继续保持原状态 |
| 新游戏 | 重建会话及 BGM，在开场和卧室淡入结束后从 0 开始 Hide |

控制器公开 `start_or_resume()`、`suspend()`、`set_puzzle_active(active)`、`stop()`，由菜单和常驻游戏协调调用。`main.gd` 的谜题白名单为 `well_memory`、`fish_tank_memory`、`brush_wash_memory`、`tent_storage_memory`；洗笔桶前三句对白包含在谜题模态中，开始对白即切 SEEK。组合剧情沿用同一谜题模态：微剧情读完回选碎片时保持 SEEK，原三处 CG 返回探索时切回 Hide。帐篷收纳盒的 18 条微剧情、三页前置对白、前两次抵抗演出与情节块 4 的两条正式导向处于谜题模态中，沿用 SEEK，微剧情或抵抗对白返回填词时保持 SEEK。完整读完情节块 4 后，GameUI 同黑屏接入第五幕，`opaque_dialogue` 保持 SEEK；第五幕黑底回忆、装置对白与结局正文均沿用该规则。真实回忆后的探索提示、终局页及 Esc 提前退出时切回 Hide。新增地点和普通弹窗不另建 BGM 播放器；调整音乐语义时同步控制器、菜单生命周期、谜题状态与架构文档。

## 设置与音量总线

`default_bus_layout.tres` 固定 `Master`、`BGM`、`SFX` 三条总线，后两条输出至 `Master`。菜单外壳创建 `scripts/ui/game_settings.gd` 服务，在游戏会话外保留设置；服务加载后立即应用音量，并为缺失的 `BGM`、`SFX` 总线提供运行时补齐。新音效播放器需指定 `SFX` bus。当前未添加音效素材或音效播放器，音效滑杆已控制并保存该总线的音量。

音效音量、背景音乐和亮度均为 `0–100` 整数，默认 `100`。两条音量总线使用 `数值 / 100` 的线性增益，`100` 为 `0 dB` 总线增益，BGM 保持播放器原有 `-6 dB`；`0` 静音对应总线。拖动实时应用数值，修改音量不重建播放、不切换曲目、不调用恢复播放。

偏好独立写入 `user://settings.cfg` 的 `audio/sfx_volume`、`audio/music_volume` 和 `display/brightness`。加载仅接受有限的整数或浮点数，四舍五入并限制在 `0–100`；其他值恢复该项默认值。设置与会话进度分开，新游戏保留设置。滑杆松开、返回、重置时保存，服务在窗口关闭或退出场景树时为未保存修改兜底，拖动过程不逐像素写盘。亮度数值由菜单外壳的全屏黑色遮罩应用，透明度为 `(100 - brightness) × 0.006`，最低保留约 40% 显示亮度；重置同时恢复三项默认值。

## 替换与验收

1. 使用用户确认的音频，按原字节归档，核对来源与项目副本的 SHA-256，并更新独立音频清单。
2. 成对核对采样率、声道、帧长、起点和循环范围，保留两条同位置切换的时间关系；同时维护双向转换规则。
3. 交付完整项目内 WAV、`.import`、资源和脚本，微信来源文件夹无需随游戏交付。
4. 原文件归档及参数已静态核对，四处组合剧情沿用已有音轨、音量和切换参数；未由 Codex 启动试玩、自动化测试或音频试听。当前音乐接入待用户试听，记录保持“听感待确认”；用户明确要求测试或修复 bug 时，再按受影响的状态与音频行为验证。

2026-10-18 设置服务、总线配置、BGM 输出引用及文档已按文件静态核对；本轮未启动引擎、试玩、自动化测试或音频试听。音量听感、静音后恢复、设置持久化及暂停返回体验待用户手工验收。
