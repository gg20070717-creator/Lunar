# Lunar

Godot 4.7.2 / GDScript / 2D 叙事探索与记忆还原游戏。本机项目目录为 `D:/godot/demo/demo2`，仓库名为 `Lunar`。

## 运行与操作

使用 Godot 4.7.2 Mono 打开本目录的 `project.godot`，按 F5 从主菜单运行。项目入口为 `scenes/ui/main_menu.tscn`，菜单在新游戏剧情结束后创建 `main.tscn` 游玩场景。参考画布为 1920×1080。

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD |
| 靠近物件交互 | F；当前目标显示轮廓光晕 |
| 点击查看 | 左键，仅部分物件支持 |
| 普通对白补全或翻页 | 左键、Enter、空格或 F |
| 装置最终选择 | 点击文字选项、↑↓ 选择并 Enter/空格/F 确认，或数字 1/2 |
| 当前弹层返回 / 探索界面暂停 | Esc |
| 记忆还原 | 左键拖拽月相与词语，Enter 按阶段确认 |
| 设置滑杆 | 点击/拖动横条或箭头、触摸拖动；聚焦后 ←/→ 或 Home/End 调节，右侧显示 0–100 数值 |
| 微剧情 / 正式剧情 | 左键、Enter、空格或 F 补齐并继续；微剧情回选碎片，正式剧情按分支接后续；Esc 退出谜题 |

首次创建游玩实例时显示一次键帽操作说明，首个按键用于关闭说明。切换地点、暂停和继续期间保持当前会话。

水井、鱼缸、画室洗笔桶与帐篷收纳盒共享每局一次的碎片拖拽引导：按住左键，将月相碎片拖到对应物体上松开。引导显示时可直接拖拽，首块成功投入后淡出；任意非 Esc 按键可收起并消耗该次输入，Esc 仍退出谜题。四处碎片接收区域覆盖各自物体区域并保留边缘容错，词语拖回取消使用各自水面或盒盖范围。

四处月相均接入用户五张透明 PNG，按 A—E 从残到满对应原文件 5、4、3、2、1。选碎片时水面初始无词，每投入一块只显现对应一个词，可继续投入；按 Enter 后已投入词统一飞出为词牌，动画结束进入填词。

每次新游戏完整播放开场并重建状态；继续游戏恢复当前进程内的位置和进度。关闭或重新运行项目后进度重置。主菜单与暂停界面共用设置页，音效音量、背景音乐与亮度即时生效，默认均为 100，偏好独立保存至 `user://settings.cfg` 并跨新游戏保留。载入游戏与制作人员名单当前为预留页面。

## 开发与交付
